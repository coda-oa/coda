# Reporting

The **Reporting** area brings together everything CODA produces from your funding request, publication and contract data for reporting purposes. Open it from the menu item of the same name; it offers three tools:

| Tool | What it does | Documentation |
|---|---|---|
| **Funding Request Statistics** | Interactive statistics: publications, spend and their breakdowns by institution, publisher, contract and more, filterable and with period comparison | [Statistics](statistics.md) |
| **openCost Reports** | Standardized XML reports of publication costs and contracts for funding organizations and transparency initiatives | [openCost Reports](opencost.md) |
| **Funding Request CSV Export** | One row per funding assignment for analysis in spreadsheet applications | [CSV Export](csv-export.md) |
